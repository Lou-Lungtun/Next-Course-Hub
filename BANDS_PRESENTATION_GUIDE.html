คู่มือซ้อมอธิบายหน้า “วงดนตรีที่ชื่นชอบ”

ใช้เอกสารนี้เป็นแนวทางในการนำเสนอ ไม่จำเป็นต้องท่องทุกคำ ควรจำลำดับการทำงานและอธิบายด้วยคำพูดของตัวเอง

1. เริ่มนำเสนออย่างไร

“งานนี้ผมสร้างหน้าเว็บแสดงวงดนตรีที่ชื่นชอบ โดยใช้แนวคิด Component-based UI ใน Next.js ครับ ผมแยกงานออกเป็น 4 ส่วน คือ Type สำหรับกำหนดโครงสร้างข้อมูล, Data สำหรับเก็บข้อมูลวงดนตรี, Page สำหรับวนข้อมูลทั้งหมด และ BandCard สำหรับแสดงข้อมูลทีละวง นอกจากนี้ยังใช้ map ซ้อนกันเพื่อแสดงทั้งวงดนตรีและสมาชิกครับ”

หลังพูดภาพรวมแล้ว ให้เปิดหน้า /bands ให้อาจารย์เห็นผลลัพธ์ จากนั้นจึงเปิดโค้ดตามลำดับต่อไปนี้

1. band.ts → 2. bandsdata.ts → 3. bands/page.tsx → 4. BandCard.tsx → 5. globals.css

2. ขั้นที่หนึ่ง: อธิบาย Type

เปิดไฟล์ src/types/band.ts

“ผมเริ่มจากสร้าง Type ก่อน เพื่อกำหนดว่าข้อมูลสมาชิกและวงดนตรีต้องมีอะไรบ้าง Type Member มี id, name และ role ส่วน Type Band มี id, name, genre, image และ members โดย members เป็น Array ของ Member ครับ” 
export type Member = {
  id: number;
  name: string;
  role: string;
};

export type Band = {
  id: number;
  name: string;
  genre: string;
  image?: string;
  members: Member[];
};

ประเด็นที่ควรอธิบาย:

  • export ทำให้ไฟล์อื่น import Type นี้ไปใช้ได้
  • string คือข้อความ และ number คือตัวเลข
  • image? มีเครื่องหมายคำถาม หมายถึงไม่ใส่รูปก็ได้
  • Member[] หมายถึง Array ที่เก็บสมาชิกหลายคน
  • TypeScript จะแจ้ง error หากข้อมูลขาด property สำคัญหรือใส่ชนิดผิด

3. ขั้นที่สอง: อธิบายการแยกข้อมูล

เปิดไฟล์ src/data/bandsdata.ts

“ต่อมาผมแยกข้อมูลจำลองไว้ในไฟล์ bandsdata.ts ไม่ได้เขียนข้อมูลไว้ใน Component ทำให้เพิ่ม ลบ หรือแก้ข้อมูลวงดนตรีได้ง่าย และ Component มีหน้าที่แสดงผลเพียงอย่างเดียวครับ” 
import type { Band } from "@/types/band";

export const bands: Band[] = [
  {
    id: 1,
    name: "Dept",
    genre: "Synth-pop",
    image: "/images/bands/Dept.jpg",
    members: [
      { id: 1, name: "ชื่อสมาชิก", role: "หน้าที่" },
    ],
  },
];

ประเด็นที่ควรอธิบาย:

  • import type นำ Band มาใช้ตรวจข้อมูล ไม่ได้สร้างสิ่งที่แสดงบนหน้าเว็บ
  • bands: Band[] ระบุว่า Array นี้ต้องเก็บข้อมูลตามโครงสร้าง Band
  • export const ทำให้หน้าอื่นนำ Array bands ไปใช้ได้
  • สร้างข้อมูลครบอย่างน้อย 3 วงตามโจทย์
  • แต่ละวงมี Array members ของตัวเอง
  • id ของวงไม่ซ้ำกัน ส่วน id สมาชิกสามารถเริ่มใหม่ในแต่ละวงได้ เพราะแต่ละวงมีรายการสมาชิกคนละชุด

4. ขั้นที่สาม: อธิบาย Parent Component และ map แรก

เปิดไฟล์ src/app/bands/page.tsx

“ไฟล์ page.tsx เป็น Parent Component ของหน้า /bands ครับ หน้านี้ import ข้อมูล bands และ Component BandCard จากนั้นใช้ bands.map วนข้อมูลทุกวง แล้วสร้าง BandCard หนึ่งใบต่อหนึ่งวง พร้อมส่งข้อมูลผ่าน prop ชื่อ band ครับ” 
{bands.map((band) => (
  <BandCard key={band.id} band={band} />
))}

อธิบายโค้ดทีละส่วน:

  • bands คือ Array วงดนตรีทั้งหมด
  • .map() วนสมาชิกทุกตัวใน Array และสร้าง JSX กลับมา
  • band คือข้อมูลวงปัจจุบันในแต่ละรอบ
  • <BandCard /> สร้าง Component หนึ่งใบ
  • key={band.id} ช่วยให้ React ระบุแต่ละรายการได้
  • band={band} ส่ง Object วงปัจจุบันให้ Child Component ผ่าน Props

5. ขั้นที่สี่: อธิบาย Child Component

เปิดไฟล์ src/components/BandCard.tsx

“BandCard เป็น Child Component ที่รับข้อมูลหนึ่งวงผ่าน Props ครับ ผมกำหนด Props Type ไว้ว่า band ต้องเป็น Type Band จากนั้นนำข้อมูลมาแสดงเป็นรูป ชื่อวง แนวเพลง และรายชื่อสมาชิก” 
type BandCardProps = {
  band: Band;
};

export default function BandCard({ band }: BandCardProps) {

สิ่งที่ควรอธิบาย:

  • BandCardProps เป็นกติกาของ Props
  • { band } คือ destructuring ดึง band ออกจาก Props
  • : BandCardProps ให้ TypeScript ตรวจ Props ที่ Component รับ
  • Component เดียวสามารถนำกลับมาใช้แสดงวงกี่วงก็ได้ เพราะข้อมูลมาจาก Props

อธิบายการแสดงรูป

{band.image && (
  <Image
    src={band.image}
    alt={`รูปวง ${band.name}`}
    width={500}
    height={300}
    sizes="..."
  />
)}
“ผมใช้ band.image และเครื่องหมาย && เพื่อตรวจว่ามีรูปก่อนแสดง ถ้าไม่มีรูป หน้าเว็บก็ยังทำงานได้ ส่วน Image เป็น Component ของ Next.js ที่ช่วยจัดการขนาดและการโหลดรูปครับ”
  • src คือตำแหน่งรูป
  • alt อธิบายรูปสำหรับ accessibility และกรณีรูปโหลดไม่สำเร็จ
  • width/height กำหนดสัดส่วนพื้นฐานและลด Layout Shift
  • sizes บอกขนาดรูปที่เหมาะกับมือถือ แท็บเล็ต และ Desktop

อธิบาย map สมาชิก

{band.members.map((member) => (
  <li key={member.id}>
    <span>{member.name}</span>
    <small>{member.role}</small>
  </li>
))}
“ภายใน BandCard ผมใช้ map อีกครั้งกับ band.members เพื่อแสดงสมาชิกทุกคนของวงนั้น โดยสร้าง li หนึ่งรายการต่อหนึ่งคน และใช้ member.id เป็น key ครับ”

6. ขั้นที่ห้า: อธิบายรูปภาพ

“ผมเก็บรูปไว้ใน public/images/bands เมื่อเรียกใช้ไม่ต้องเขียนคำว่า public จึงใช้ path เริ่มจาก /images/bands ได้เลยครับ” 
ไฟล์จริง: public/images/bands/Dept.jpg
path ในข้อมูล: /images/bands/Dept.jpg
ชื่อไฟล์ ตัวพิมพ์เล็ก-ใหญ่ ช่องว่าง และนามสกุลต้องตรงกับ path ในข้อมูล โดยเฉพาะเมื่อ deploy บนระบบที่แยกตัวพิมพ์เล็กกับใหญ่

7. ขั้นที่หก: อธิบาย CSS

“ส่วน CSS ผมใช้ Grid จัดการ์ดบนหน้าจอใหญ่ 3 คอลัมน์ แล้วใช้ media query ปรับเป็น 2 คอลัมน์บนแท็บเล็ตและ 1 คอลัมน์บนมือถือ ภายในการ์ดใช้ Flexbox เรียงรูปและเนื้อหาในแนวตั้งครับ”
CSSสิ่งที่ควรอธิบาย
display: gridเปิด Grid สำหรับจัดการ์ดหลายใบ
repeat(3, minmax(0, 1fr))สร้าง 3 คอลัมน์ขนาดเท่ากัน
gap: 24pxเว้นระยะระหว่างการ์ด
display: flexจัดส่วนต่าง ๆ ภายในการ์ด
flex-direction: columnเรียงรูปและข้อความจากบนลงล่าง
aspect-ratio: 5 / 3ทำให้กรอบรูปทุกใบมีสัดส่วนเท่ากัน
object-fit: coverทำให้รูปเต็มกรอบโดยไม่ถูกยืด
border-radiusทำให้มุมการ์ดและรูปโค้ง
box-shadowสร้างเงาให้การ์ดมีมิติ
:hoverเปลี่ยนรูปแบบเมื่อผู้ใช้ชี้เมาส์
transitionทำให้เอฟเฟกต์เปลี่ยนอย่างนุ่มนวล
@media (max-width: 900px)ปรับเหลือ 2 คอลัมน์บนหน้าจอกลาง
@media (max-width: 640px)ปรับเหลือ 1 คอลัมน์บนมือถือ

8. สคริปต์นำเสนอฉบับเต็มแบบสั้น

“หน้า Favorite Bands นี้ผมใช้ Next.js และ TypeScript ครับ เริ่มจากสร้าง Type Member และ Band เพื่อกำหนดรูปแบบข้อมูล จากนั้นแยกข้อมูลจำลองอย่างน้อย 3 วงไว้ใน bandsdata.ts เพื่อไม่ให้ข้อมูลปนกับ Component ใน page.tsx ผม import ข้อมูลทั้งหมดแล้วใช้ bands.map สร้าง BandCard หนึ่งใบต่อหนึ่งวง โดยส่งข้อมูลผ่าน Props ส่วน BandCard รับข้อมูลหนึ่งวงมาแสดงรูป ชื่อ แนวเพลง และใช้ band.members.map แสดงสมาชิกทุกคน รูปเก็บไว้ใน public/images/bands และใช้ Next Image แสดงผล สุดท้ายใช้ CSS Grid และ media query จัดหน้าให้รองรับทั้ง Desktop Tablet และ Mobile ครับ”

9. คำถามที่อาจารย์น่าจะถาม

คำถามแนวตอบ
ทำไมต้องสร้าง Component?ตอบ: เพื่อแยกหน้าที่ ลดโค้ดซ้ำ และใช้ BandCard เดียวแสดงวงได้หลายวงจากข้อมูลที่ต่างกัน
Parent กับ Child คือไฟล์ไหน?ตอบ: BandsPage เป็น Parent เพราะถือข้อมูลและสร้าง BandCard ส่วน BandCard เป็น Child เพราะรับข้อมูลผ่าน Props
Props คืออะไร?ตอบ: ข้อมูลที่ Parent ส่งให้ Child ในงานนี้ส่ง Object หนึ่งวงผ่าน prop ชื่อ band
ทำไมใช้ map?ตอบ: เพื่อเปลี่ยนข้อมูลแต่ละตัวใน Array ให้เป็น JSX โดยไม่ต้องเขียนการ์ดหรือสมาชิกซ้ำเอง
ในงานนี้มี map กี่จุด?ตอบ: 2 จุด จุดแรกวนวงทั้งหมดใน BandsPage จุดที่สองวนสมาชิกของแต่ละวงใน BandCard
map ต่างจาก forEach อย่างไร?ตอบ: map คืนค่า Array ใหม่ จึงเหมาะกับการสร้าง JSX หลายรายการ ส่วน forEach ไม่คืน Array
key มีไว้ทำไม?ตอบ: ช่วยให้ React ระบุรายการแต่ละตัว และอัปเดตเฉพาะรายการที่เปลี่ยนได้ถูกต้อง
ทำไมไม่ใช้ index เป็น key?ตอบ: id มีความคงที่กว่า index โดยเฉพาะเมื่อเพิ่ม ลบ หรือสลับลำดับข้อมูล
Type มีประโยชน์อย่างไร?ตอบ: ช่วยตรวจว่าข้อมูลครบและชนิดถูกต้องก่อนรัน ลดข้อผิดพลาด เช่นใส่ id เป็นข้อความ
เครื่องหมาย ? หลัง image คืออะไร?ตอบ: Optional property หมายความว่าวงนั้นไม่มีรูปก็ได้
ทำไมต้องใช้ band.image &&?ตอบ: เพราะ image เป็น optional จึงตรวจว่ามีก่อนแสดง Image ป้องกันการส่งค่า undefined ให้รูป
ทำไมแยกข้อมูลออกจาก Component?ตอบ: เพื่อแยกหน้าที่ ไฟล์ data ดูแลข้อมูล ส่วน Component ดูแลการแสดงผล ทำให้แก้และนำกลับมาใช้ซ้ำง่าย
ทำไมใช้ import type?ตอบ: เพราะ Band ใช้สำหรับตรวจ Type เท่านั้น ไม่ต้องรวมเป็น JavaScript ตอนรัน
@/ หมายถึงอะไร?ตอบ: เป็น path alias ที่ชี้ไปยังโฟลเดอร์ src ทำให้ import สั้นและอ่านง่าย
ทำไมใช้ Next Image?ตอบ: ช่วยปรับขนาดรูป โหลดรูปอย่างเหมาะสม และลดปัญหาหน้าเลื่อนตอนรูปโหลด
ทำไมต้องมี alt?ตอบ: เพื่อ accessibility และอธิบายรูปเมื่อโหลดไม่สำเร็จ
ทำให้หน้า responsive อย่างไร?ตอบ: ใช้ CSS Grid กับ media query เปลี่ยนจาก 3 เป็น 2 และ 1 คอลัมน์ตามความกว้างหน้าจอ
ถ้าต้องการเพิ่มวงที่ 4 ทำอย่างไร?ตอบ: เพิ่ม Object ใหม่ใน Array bands ให้ตรงกับ Type Band หน้าเว็บจะสร้าง BandCard เพิ่มให้อัตโนมัติ
ถ้าต้องการเพิ่มสมาชิกทำอย่างไร?ตอบ: เพิ่ม Object ใน members ของวงนั้น members.map จะแสดงสมาชิกใหม่ให้อัตโนมัติ

10. จุดที่ควรสาธิตให้อาจารย์ดู

  1. เปิดหน้า /bands ให้เห็นวงครบ 3 วง
  2. ย่อหน้าต่างเพื่อให้เห็น Grid เปลี่ยนจาก 3 เป็น 2 และ 1 คอลัมน์
  3. ชี้เมาส์บนการ์ดเพื่อแสดง hover
  4. เพิ่มสมาชิกชั่วคราวใน bandsdata.ts แล้วให้ดูว่าหน้าเว็บเพิ่มให้อัตโนมัติ
  5. ชี้ให้เห็น map สองจุดและอธิบายความแตกต่าง
  6. ชี้ให้เห็นว่า Component ไม่มีข้อมูลวงเขียนตายตัว แต่รับข้อมูลผ่าน Props

11. สิ่งที่ควรจำให้ได้ก่อนนำเสนอ

  • จำหน้าที่ของไฟล์ทั้ง 4 ไฟล์ให้ได้
  • จำว่า Parent ส่ง band={band} ให้ Child
  • จำว่า map แรกวนวง และ map ที่สองวนสมาชิก
  • จำเหตุผลของ key, Type และการแยกข้อมูล
  • ไม่จำเป็นต้องจำ CSS ทุกค่า แต่ควรอธิบาย Grid, Flexbox, object-fit และ media query ได้
วิธีตอบเมื่อจำไม่ได้: เปิดโค้ดแล้วไล่ตามข้อมูลจาก bandsdata.ts ไป page.tsx และ BandCard.tsx อย่าเดาสุ่ม ให้บอกตามหน้าที่ของโค้ดที่เห็น
